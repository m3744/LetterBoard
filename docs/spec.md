# iPad 溝通輔助 App 詳細需求規格書

**專案名稱**：字母溝通板（暫定）  
**平台**：iPad（iPadOS 17 以上）  
**開發語言**：Swift + SwiftUI  
**文件用途**：供開發與 LLM 輔助程式碼生成使用

---

## 1. 緣起

使用者為 17 歲中度自閉症青少年。他抗拒實體鍵盤，但過去曾成功使用「類鍵盤／字母板」方式與老師溝通，具備識字與拼字能力。

參考真實案例（母親為自閉症兒子製作鍵盤刺青以輔助溝通）以及現有數位字母板工具，決定開發一款專屬的 iPad 溝通 App。目標是提供一個**大按鍵、低干擾、可切換布局、支援語音朗讀**的工具，讓他能以熟悉的點選字母方式表達想法。

---

## 2. 目標使用者

- 主要使用者：17 歲中度自閉症青少年（有拼字能力，抗拒實體鍵盤觸覺回饋）
- 次要使用者：家長（調整設定與常用句）

使用特點：需要大觸控目標、介面清晰可預期、低感官刺激、操作簡單。

---

## 3. 核心目標

1. 提供超大按鍵的虛擬鍵盤，降低操作困難
2. 支援注音與 QWERTY 兩種布局，可快速切換
3. 文字顯示區精簡（小），不佔用主要空間
4. 具備明顯的語音朗讀功能
5. 介面清晰、元素有明確文字標示
6. 完全離線、穩定、隱私安全

---

## 4. 功能需求

### 4.1 MVP 必須功能（第一版）

**F1. 雙布局超大虛擬鍵盤**
- 支援「注音（ㄅㄆㄇ）」與「QWERTY」兩種布局
- 一鍵切換布局
- 按鍵必須大（建議觸控區域至少 70×70 pt 以上，可再加大）
- 按鍵間距充足，減少誤觸
- 按鍵文字高對比、清楚可讀

**F2. 精簡文字顯示區（小）**
- 位置在畫面最上方
- 高度較小（建議單行或最多兩行）
- 即時顯示目前輸入的文字
- 支援左右捲動（當文字較長時）
- 具備「刪除單字」與「全部清除」功能

**F3. 語音朗讀**
- 使用系統 AVSpeechSynthesizer
- 有明確標示的「朗讀」按鈕
- 點擊後朗讀目前顯示區的文字
- 預設使用繁體中文語音
- 按鈕位置固定、容易找到、足夠大

**F4. 基本功能鍵與標示**
- 空白鍵
- 常用標點：，。？！
- 所有按鈕皆有**明確文字標示**（不可只有圖示）
- 布局切換按鈕有清楚標示「注音」／「QWERTY」

**F5. 系統基本要求**
- 完全離線可用
- 支援直式與橫式自動適配
- 啟動快速、操作即時反應
- 無廣告、無追蹤、無登入

### 4.2 第二階段功能（MVP 驗證後）

- 常用短句快速鍵（可自訂，建議 6–10 個）
- 按鍵大小微調選項
- 語音速度調整
- 簡單家長設定頁（可鎖定）
- 高對比主題切換

---

## 5. 介面需求（重要）

### 5.1 整體布局原則（由上到下）

1. **頂部：精簡文字顯示區（小）**
   - 高度較低
   - 顯示目前輸入內容
   - 旁邊或內部有「刪除」「清除」按鈕

2. **中上：功能控制列**
   - 「朗讀」按鈕（最明顯、有明確文字標示）
   - 布局切換按鈕（明確標示「注音 / QWERTY」）
   - 其他必要功能按鈕

3. **下方：超大鍵盤區（主要空間）**
   - 佔畫面最大比例（建議 70% 以上）
   - 按鍵盡量大、間距充足
   - 清晰高對比

### 5.2 視覺與互動原則

- 介面清晰、分區明確
- 所有可點擊元素都有**明確文字標示**
- 低感官刺激（少動畫、無閃爍、無多餘音效）
- 高對比配色，確保可讀性
- 按鍵回饋明確但不刺眼
- 風格中性實用，避免幼童卡通風格

---

## 6. 非功能需求

- **易用性**：大觸控目標、操作步驟少、結果可預期
- **穩定性**：長時間使用不閃退、反應即時
- **隱私**：資料只存在本機，不上傳
- **效能**：點擊後無明顯延遲
- **相容性**：主要支援較新的 iPad，最低 iPadOS 17

---

## 7. 參考專案

- **SpellRBoard**：最接近的參考（數位字母板 + TTS + 可切換 QWERTY，專為自閉症設計，介面簡潔）
- 其他 Letterboard 類型 App：大按鍵與訊息視窗配置參考
- 系統 AVSpeechSynthesizer：語音實作參考
- SwiftUI 自訂鍵盤範例：按鍵組件與狀態管理參考

核心原則：保持「大鍵盤點選 + 小顯示區 + 明確朗讀」的單純本質。

---

## 8. 建議技術架構

**技術選型**：
- Swift + SwiftUI
- 語音：AVSpeechSynthesizer
- 狀態管理：@Observable 或 ObservableObject
- 本地儲存：AppStorage / UserDefaults

**建議模組結構**：

```
AlphabetBoardApp/
├── App/AlphabetBoardApp.swift
├── Views/
│   ├── ContentView.swift
│   ├── TextDisplayView.swift          // 小顯示區
│   ├── ControlBarView.swift           // 朗讀、切換等
│   ├── KeyboardView.swift
│   ├── ZhuyinKeyboardView.swift
│   ├── QWERTYKeyboardView.swift
│   └── KeyButton.swift
├── ViewModels/
│   └── BoardViewModel.swift
├── Models/
│   ├── LayoutType.swift
│   └── KeyItem.swift
├── Services/
│   └── SpeechService.swift
└── Utilities/
    └── Constants.swift
```

**核心狀態**：
- currentText: String
- currentLayout: LayoutType（.zhuyin / .qwerty）

**資料流**：
點擊按鍵 → 更新 currentText → 顯示區更新  
點擊朗讀 → SpeechService 播放 currentText  
點擊切換 → 更新 currentLayout → 切換鍵盤視圖

---

## 9. 開發優先順序

**第一階段（MVP）**：
1. 完成超大鍵盤（注音 + QWERTY 切換）
2. 精簡小顯示區 + 刪除/清除
3. 明顯的「朗讀」功能
4. 基本直橫向適配
5. 所有按鈕有明確文字標示

**第二階段**：
- 根據實際使用調整按鍵大小與間距
- 加入常用短句
- 簡單設定選項

---

## 10. 其他注意事項

- 注音布局 MVP 可先實作直接輸入注音符號，選字功能後期再評估
- 按鍵大小與間距建議做成常數，方便快速調整
- 優先確保兒子「願意使用」，功能完整度次之
- 介面必須清晰、標示明確、鍵盤佔最大空間、顯示區保持精簡
